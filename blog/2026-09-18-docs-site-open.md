## 무엇이 달라지나요

흩어져 있던 작업 문서를 한곳에 모으고, GitHub 저장소에서 버전 관리합니다. 누가 언제 무엇을 바꿨는지 히스토리가 남고, 문서 변경도 코드처럼 Pull Request로 리뷰할 수 있습니다.

## 문서를 고치려면

각 페이지 맨 아래 **"Edit this page"** 링크를 누르면 GitHub에서 바로 수정할 수 있습니다. 자세한 절차는 [문서 기여 방법](/docs/contributing)에 정리해 두었습니다.

## 이 공간의 용도

이 "업데이트" 게시판에는 문서나 시스템에 큰 변경이 생겼을 때 공지를 남깁니다. 평소 참고하는 내용은 게시판이 아니라 문서 쪽에 정리해 주세요.
